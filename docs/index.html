CARACTERÍSTICAS

No es solo un descargador

SYNC DE SOUNDCLOUD

Conectá tu cuenta y sincronizá tus likes automáticamente, con historial de qué ya bajaste y qué es nuevo — programable con el Task Scheduler de Windows.

DUPLICADOS, DE VERDAD

Matching difuso de nombre contra toda tu biblioteca, y huella de audio (Chromaprint) como red de seguridad — atrapa el mismo tema con nombre distinto sin confundir remixes.

BPM Y TONALIDAD

Cada descarga se analiza con librosa y queda taggeada con BPM y tonalidad (Camelot o musical) — Serato y Rekordbox la leen directo, sin reanalizar.

MULTI-FORMATO

MP3 128/256/320 kbps o FLAC cuando está disponible, desde SoundCloud y YouTube, con metadata y carátula incrustadas automáticamente.

POST-PROCESAMIENTO

Normalización de volumen y eliminación de silencios sin tocar nada a mano — queda listo para tu biblioteca o para mezclar.

.EXE STANDALONE

Empaquetada para Windows sin requerir Python instalado — ffmpeg y fpcalc van embebidos. Cola en tiempo real, pausa y cancelación.

INSTALACIÓN

Arrancá en un par de minutos

OPCIÓN 1 — .EXE (WINDOWS)

Compilá tu propio ejecutable firmado localmente. No requiere Python instalado.

# clona el repo
git clone https://github.com/Noull999/music-downloader.git
cd music-downloader
pip install -r requirements.txt
python scripts/build.py
# genera dist/MusicDownloader.exe

OPCIÓN 2 — DESDE CÓDIGO FUENTE

Para Windows, macOS o Linux, corriendo directo con Python 3.9+ (3.12 recomendado).

# requiere Python 3.9+ y FFmpeg
git clone https://github.com/Noull999/music-downloader.git
cd music-downloader
pip install -r requirements.txt
python main_webview.py
Esta herramienta es solo para uso personal. Respetá los términos de servicio de SoundCloud y YouTube.
